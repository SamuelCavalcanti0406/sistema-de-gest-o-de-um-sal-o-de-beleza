# sistema-de-gest-o-de-um-sal-o-de-beleza
Um sistema completo de gestão web desenvolvido para otimizar e digitalizar a rotina de um salão de beleza real. A aplicação permite o controle eficiente de agendamentos, gerenciamento da equipe de profissionais e automatiza o fechamento financeiro, incluindo o cálculo dinâmico de comissões.
